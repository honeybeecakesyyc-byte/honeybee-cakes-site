HONEY BEE CAKES — FULL EDITOR UPDATE

WHAT THIS UPDATE DOES
- Removes the tiny bee icon from the sidebar. The brand is text-only: HONEY BEE CAKES.
- Adds an editable Google Reviews section and links it to your Google Business URL.
- Makes all visible website copy available in Pages CMS under “Website text + design”, FAQ, Policies, Google reviews, Gallery, Flavour builder, and Price + size guide.
- Adds editable heading/body/UI font choices.
- Adds editable main text colours and background colours for every major section.
- Defaults headings to Bodoni Moda (Maharlika-like web alternative) and body copy to Cormorant Garamond (The Seasons-like editorial serif).
- Restores the full Sponge / Frosting / Filling / Add-in flavour builder.
- Lets you upload your own illustration for EACH cake size. If you leave the image blank, the site draws a four-section cylinder automatically.
- Keeps Bento Box available in gallery categories.
- Makes Policies editable as long-form text.

IMPORTANT: THIS UPDATE DOES NOT INCLUDE content/site.json, content/gallery.json, content/pricing.json, or content/faq.json.
That is intentional so uploading this update will NOT erase your existing logo/hero settings, gallery photos, current prices/sizes, or FAQ questions.

HOW TO UPLOAD
1. Extract this ZIP.
2. Open the extracted folder.
3. In GitHub: honeybee-cakes-site → Add file → Upload files.
4. Drag ALL items from inside this folder into the upload page.
5. Scroll down and click Commit changes.
6. Wait for the Pages deployment green check.
7. Hard refresh the live site (Ctrl + Shift + R).
8. Refresh Pages CMS. You should see:
   - Website text + design
   - Gallery
   - Google reviews
   - Flavour builder
   - Price + size guide
   - Policies
   - FAQ questions
