HONEY BEE CAKES — CUSTOMISABLE UPDATE

This update is intentionally small so it DOES NOT replace your existing:
- site.json (your uploaded logo/hero photo/contact info stay intact)
- gallery.json (your current gallery stays intact)
- pricing.json
- faq.json

It DOES replace the flavour menu with the choices from your screenshots.
It also adds a new Policies page.

UPLOAD STEPS
1. Extract this ZIP.
2. Open your GitHub repository: honeybee-cakes-site.
3. Click Add file → Upload files.
4. Drag EVERYTHING INSIDE this extracted folder into the GitHub upload area.
5. GitHub will show existing files being replaced. That is expected.
6. Click Commit changes.
7. Wait for GitHub Pages deployment to finish, then hard refresh the site (Ctrl + Shift + R).
8. Refresh Pages CMS. You should now see Policies and all the new editable Site settings fields.

IMPORTANT:
Do NOT delete your existing assets/uploads folder. This update only adds nav-bee.png to it.
